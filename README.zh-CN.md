# Compute Monitor

一个轻量的 Apple Silicon 遥测监控器，在 macOS 菜单栏显示实时指标，并在本地记录历史。

## 界面预览

正式截图将在后续版本加入。菜单栏一次显示一项指标，例如 `CPU 23%`、`GPU 91%`、`温度 61°C`、`GPU 功耗 14.0W` 或 `NET ↓12.4 MB/s ↑1.3 MB/s`。

## 功能

- 菜单栏可选择五项主要指标；简洁弹出窗口展示当前系统遥测。
- 每项指标及语言使用固定的菜单栏宽度，数值变化不会推动相邻状态栏项目。
- 从同一份共享快照持续写入本地 SQLite 历史；使用串行批量写入和 WAL。
- 支持 English 和简体中文，可立即切换，并在本地保存语言选择。
- 普通用户即可运行，无需辅助进程、常驻子进程、`powermetrics`、主动网络连接或遥测上传。

## 支持的指标

CPU 总占用及经过验证的性能核/能效核占用；GPU 活跃比例、估算的活跃加权频率与 GPU 功耗；网络下载/上传速率；Tp05/Tg05 温度；虚拟内存与统一内存字段、交换空间、内存压力及系统热状态。Network 的定义是：当前选定外部网络接口实际接收/发送流量的汇总速率。App 只读取原生累计计数器，不发送测试流量；VPN 隧道计数不会与底层链路重复相加。菜单栏中不可用或无效的数值显示为 `—`，不会伪装成零。估算值在弹出窗口和历史记录的质量字段中标明。

## 历史记录

快速样本约每 2 秒记录一次，慢速样本约每 6 秒一次；Network RX/TX 与快速样本共用时间戳、质量和实际测量窗口字段。约每 30 秒批量写入，并在正常退出时刷盘。异常退出可能丢失最近尚未提交的一批数据。弹出窗口提供记录状态、数据库大小和**打开数据文件夹**按钮。普通 SQLite 工具可读取已提交历史；参见[v4 表结构、单位与只读查询](docs/HISTORY_SCHEMA.md)。目前没有数据保留期限或聚合。一次 15 分钟的 v4 运行测得持久数据约增长 0.698 MB/小时，属于短窗口估计；详见[验证报告](docs/MINIMAL_V01_REPORT.md)。运行时 WAL 和 SHM 文件会额外占用临时磁盘空间。

## 隐私

采集和历史数据只保存在本机。App 读取网络接口计数器，但不会建立网络连接或主动测速。没有账号、网络服务、云同步、分析服务或上传。数据库保存系统指标和 App 运行元数据，不记录进程归属或工作负载标签。语言与主要指标选择存放在本地 `UserDefaults`，不写入遥测数据库。

## 系统要求

macOS 13 或更新版本的 Apple Silicon Mac，且不在 App Sandbox 中运行。当前硬件与长期运行证据来自文档记录的 M1 Max / macOS 27.0 环境；其他芯片和系统版本尚未验证。不需要 root 权限。

## 安装

目前尚无已签名或公证的可下载版本。下述构建用于本地开发。未来公开发布时，Release 说明应包含简短的 **English** 和**简体中文**两个部分。

## 从源码构建

安装包含 Swift 和 Clang 的 Apple Command Line Tools，然后运行：

```sh
sh app/build.sh
open app/ComputeMonitor.app
```

点击菜单栏图标可查看当前遥测、选择主要指标或语言、打开数据文件夹，或退出。App 以辅助应用方式运行，不显示 Dock 图标。定向检查见 [tests/README.md](tests/README.md)；[产品范围](docs/PRODUCT_SCOPE.md)定义 v0.1 的边界。

## 数据位置

数据库位于 `~/Library/Application Support/Compute Monitor/telemetry.sqlite3`。App 运行时可能存在 `-wal` 和 `-shm` 附属文件。实时备份应使用 SQLite 备份 API。外部程序可直接只读查询数据库；App 不提供 HTTP 或 socket API。

## 已知限制

IOReport 和 AppleSMC 私有接口的行为可能随系统或硬件更新而变化；不支持的能力会明确显示为不可用。GPU 功耗和加权频率是估算值，尚未经过外部校准。网络接口选择较保守：未报告 Ethernet 类型或链路速率的特殊物理接口可能不会被计入；VPN 隧道流量不单独累加。App 内没有历史图表、数据保留策略、进程归属、工作负载分析或自动调优。本地 LLM、编译、渲染等只是通用历史日志的外部使用场景。已有的 v2 数据库可能保留一张不再使用的实验表以避免丢失数据；全新或从 v1 升级的 v4 数据库不会创建它。

## 私有 API 兼容性风险

完整遥测构建刻意不使用 App Sandbox，因为测试中沙盒阻止了 IOReport 和 AppleSMC 访问。未来 macOS 版本可能改变或移除这些私有接口。当前本地构建尚未做 Developer ID 签名或发行公证。
